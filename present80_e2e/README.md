# PRESENT-80 — fully app-driven RTL → GDSII

**Design ID:** `present80-20260808T120538-05a1dc`
**Status:** `completed` (reached `gdsii`)
**Date:** 2026-08-08
**Flow:** NoeSI `chip-agent` end-to-end — spec → plan → M19 (contract/oracle/
assertions/verification) → RTL → SYNTH → PHYSICAL → SIGNOFF → human gate → GDSII.

A bit-serial PRESENT-80 block cipher (encryption-only, iterative — one round
per clock over 31 rounds), taken from a natural-language spec to a real
GDSII **entirely by the agent flow**, on the pinned IIC-OSIC-TOOLS image
(`hpretl/iic-osic-tools:chipathon26`, LibreLane v3.0.2, gf180mcuD PDK).

The RTL was generated by **Claude Opus 4.8** (RTL gen/repair + two-loop),
with Sonnet 4.6 on the cheaper stages; config
`configs/frontier-opus-rtl.yaml`. It converged on the 2nd RTL attempt —
attempt #1 failed the ground-truth vector gate (real diagnosis), attempt #2
passed all four published test vectors.

## Interface — 7 physical I/O pins (pin-constrained, bit-serial)

The full 80-bit key, 64-bit plaintext, and 64-bit ciphertext are streamed
one bit per clock, so the die needs only 7 signal pins (a parallel interface
would need ~212).

| Pin            | Dir | Width | Description |
|----------------|-----|-------|-------------|
| `clk`          | in  | 1     | Primary clock (10 ns target period). |
| `rst_n`        | in  | 1     | Asynchronous active-low reset; release synchronous to `clk`. |
| `load_en`      | in  | 1     | While high, shift one `din` bit into the load chain per rising edge. |
| `din`          | in  | 1     | Serial data in — key MSB-first (80 b), then plaintext MSB-first (64 b). |
| `shift_out_en` | in  | 1     | While high (and `done`), shift the ciphertext out on `dout`, one bit/edge. |
| `dout`         | out | 1     | Serial data out — ciphertext MSB-first. |
| `done`         | out | 1     | High once the ciphertext is computed; clears on reset or a new load. |

Plus the two power pins from the PDK cell library: `VDD` / `VSS`
(`VNW`/`VPW` tied within the standard cells).

## Operation

1. **Load (144 cycles):** shift `{key[79:0], plaintext[63:0]}` in MSB-first
   on `din` while `load_en` is high.
2. **Encrypt (~32 cycles):** auto-starts on the 144th load bit; 31 rounds of
   addRoundKey → sBoxLayer → pLayer at one round/clock, then a final
   addRoundKey. `done` asserts when complete.
3. **Unload (64 cycles):** with `done` high and `shift_out_en` high, the 64
   ciphertext bits leave MSB-first on `dout`.

Deterministic latency ≈ 144 + 32 + 64 ≈ 240 cycles.

## Functional verification — 4/4 standard vectors

The RTL was gated in-flow by a **ground-truth vector testbench**
(`chip_agent/agents/vector_tb.py`): it loads each spec vector MSB-first,
waits for `done`, unloads the ciphertext, and compares to the spec's known
value. Independently re-simulated full-length (Icarus Verilog) — all pass:

| key                    | plaintext          | ciphertext         |
|------------------------|--------------------|--------------------|
| `00…00` (80 b)         | `00…00` (64 b)     | `5579C1387B228445` |
| `FF…FF` (80 b)         | `00…00` (64 b)     | `E72C46C0F5945049` |
| `00…00` (80 b)         | `FF…FF` (64 b)     | `A112FFC72F68417B` |
| `FF…FF` (80 b)         | `FF…FF` (64 b)     | `3333DCD3213210D2` |
